# Kaspa Live Widget v1.5.1

Choose **1H, 24H, 7D or 30D** under **Setup → Chart time range**, then tap **Apply settings**. The selected range appears in both widget sizes and is saved across app restarts. Unsaved selections survive rotation.

Each currency and chart range keeps its own saved history during outages. Missing history is labelled unavailable, and old history is labelled stale. The existing 15/30/60-minute refresh schedule and the explicitly labelled 24-hour price change remain independent of the chart range.

Install `kaspa-live-widget.apk` over your existing signed release to preserve settings and widgets. The release workflow verifies the existing signing identity and increasing version code before publishing. The AAB is the Google Play upload bundle.

Validation before release: debug and release tests, lint, build, and Android 8/Android 16 emulator layout checks passed for the chart-range feature in PR #28. Physical-device acceptance remains an owner check.
