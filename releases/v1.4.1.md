# v1.4.1 — readable widget previews

- Expanded setup previews scale to the measured card width, preserving the actual widget proportions on narrow screens and after resizing.
- Compact price and DAA panels each reserve space for their reading. Single-line change messages auto-size, so unavailable feeds cannot push the DAA value out at larger text sizes. Widget typography omits extra font padding.
- Regression tests cover full readings within their panels and both previews on 240dp/360dp setup widths. Android 8 and 16 CI capture the actual debug app at normal and larger text scales.

Version code 8 updates the existing signed app through the persistent release signing key. Use the public APK to update; uninstalling first removes saved settings. The AAB is for the owner's Play Console. Physical launcher resizing, battery restrictions and Play-delivered updates still require owner testing.
