# Kaspa Live Widget v1.6.0

The signed APK gains built-in update checks and downloads. Open Setup → App updates, tap Update now, then approve installation through Android. Daily checks show Update on the widget when a newer stable release is available. Downloads require a tap and are verified against the release checksum, app identity, version, and existing signing certificate.

Existing installations need one upgrade to v1.6.0 to gain the updater. Updates preserve saved settings and widget placement. The debug app is separate and cannot update to the public signing identity.

The Play upload bundle excludes the direct APK updater and install permission. Google Play distribution still requires the owner’s account, testing, and approval.

Physical-device acceptance of the complete in-app permission/installation flow remains required before describing it as device-proven.
