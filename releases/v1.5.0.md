# v1.5.0 — Your widget, your look

- Adjust chart intensity from 0–100%; the default 50% keeps the line behind the readings.
- Choose independent clock, price, chart and network colors, or link them to your text/accent again.
- Save up to 20 named looks locally; loading previews a draft before Apply settings. Currency and refresh interval stay unchanged.
- Clearer offline, refreshing, stale and unavailable feedback keeps cached values and shows separate price/network ages.
- HQ provides a dedicated Android download and installation guide with stalled-download help.

Version code 10 uses the persistent release signing identity. Install over your existing signed app to retain settings and widgets. Old custom palettes inherit their accent until you choose independent colors.
