# v1.4.2 — X-ray and custom colors

- X-ray adds black glass, white readings, grayscale panels, a monochrome Kaspa mark and a white chart glow.
- Custom colors lets you edit background, text and accent with RGB sliders or a six-digit hex code. The accent colors the chart, price, clock and logo.
- Changes preview before saving, survive setup rotation, and apply to both widget sizes when saved. Cancel leaves the draft alone; reset restores the default custom palette. Low-contrast combinations get a readability hint.
- Existing dark/light choices, currency, refresh interval and chart settings are preserved on update.

Version code 9 uses the existing persistent signing identity. Install over the previous signed APK to keep saved settings and widgets.
