# Kaspa Live Widget 1.3.0

Free, open-source Kaspa home-screen widgets for Android 8.0 and newer.

## In this release

- Neon glass design with the Kaspa mark and an optional real 24-hour price chart.
- Compact 2×2 and expanded 4×4 widgets showing time, KAS price and DAA score; the expanded view also shows observed BPS and hashrate.
- Setup previews for both widget sizes, USD/EUR/GBP, dark/light appearance and 15/30/60-minute refresh intervals.
- Explicit **Apply settings** and **Save & add** controls, with draft choices preserved through phone rotation.
- Manual refresh feedback and saved reading timestamps during partial feed outages.
- Price-change colors and readable labels across both layouts and themes.

## Installation

Once the signed release is published, download `kaspa-live-widget.apk` from its release assets. Open it on your phone and allow installation from that browser or file manager when Android prompts. Open the app, choose your settings and tap **Save & add**; alternatively, long-press the home screen, choose **Widgets**, and add **Kaspa 2×2** or **Kaspa 4×4**.

CI debug builds install as a separate test app. The public release does not replace that debug installation or migrate its settings. Future public updates must use the same signing key to preserve the release app's settings and widgets.

## Data and timing

The widget reads public APIs and does not connect to a wallet or request keys. Background refresh can be delayed by Android; tap the widget for a manual refresh. Observed BPS requires two network readings. Missing or stale data is labelled, and exchange fallback is approximately USD only. This is not a real-time trading feed.
