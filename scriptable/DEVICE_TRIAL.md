# Scriptable iPhone trial

Status: **pending**. The developer workspace has no physical iPhone/Scriptable runtime. Automated adapters do not substitute for this trial.

Record iPhone model, iOS version, Scriptable version, date, and findings when completing this checklist:

- [ ] Copy the raw script from GitHub in Safari into a new Scriptable script without downloading.
- [ ] Run the medium preview; confirm the proper Kaspa logo, USD price, 24-hour change, actual chart, DAA score, and hashrate.
- [ ] Run a second preview after 30 seconds; confirm observed average BPS, or a clearly labeled unavailable feed.
- [ ] Place small, medium, and large Home Screen widgets and select the script.
- [ ] Check all four theme parameters and `chart=off`.
- [ ] Check readability on a small-screen iPhone, larger accessibility text, and normal/tinted Home Screen appearance.
- [ ] Verify tapping **Run Script**, choosing a preview, and returning to the Home Screen.
- [ ] Turn on Airplane Mode, run again, and verify cached values retain old timestamps and the footer reports delayed feeds. Restore networking.
- [ ] Confirm an old quote/network/hash shows stale with its age at the next render.
- [ ] Observe an automatic background refresh with the phone locked/unlocked; record actual interval without promising the requested timing.
- [ ] Restart the phone and confirm the configured script and local cached readings remain available.

If import, rendering, or data parsing fails, retain the Scriptable error message and line number, plus a screenshot of the widget. Do not include personal account information.
